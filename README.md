# RISC-V RV32I Single-Cycle Core

Building a complete single-cycle RISC-V RV32I processor in Verilog.

**Platform**: MacBook Air M2  
**Tools**: Icarus Verilog + GTKWave + VS Code  
**Author**: Rashmika Peddini

## Project Structure
- `rtl/`     → Design files
- `tb/`      → Testbenches
- `sim/`     → Waveforms & logs
- `docs/`    → Diagrams & notes
